# ✈️ Airline Customer Satisfaction Analysis

> An end-to-end Data Analytics and Machine Learning project to analyze airline passenger satisfaction, identify important factors affecting customer experience, and build classification models for satisfaction prediction.

---

## 📌 Project Overview

Customer satisfaction is an important indicator of service quality in the airline industry.

This project analyzes airline customer satisfaction using **Python, Pandas, Matplotlib, and Scikit-learn**.

The project follows a complete analytics workflow:

**Data Understanding → Data Cleaning → Exploratory Data Analysis → Feature Engineering → Machine Learning → Model Evaluation → Dashboard**

---

## 🎯 Project Objectives

- Understand and prepare the dataset
- Perform data cleaning and preprocessing
- Analyze customer satisfaction patterns
- Perform Exploratory Data Analysis (EDA)
- Create meaningful features
- Analyze flight delays and flight distance
- Build machine learning classification models
- Compare model performance
- Evaluate model results
- Identify important features
- Create a final analytical dashboard
